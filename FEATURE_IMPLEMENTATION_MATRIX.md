## 1. Feature Status Legend
* **Complete:** Fully implemented in frontend and backend, verified with real code logic.
* **Partial:** Functional core exists, but secondary capabilities (e.g., real payment gateway vs. simulator) are simulated or unintegrated.
* **UI Only:** Visual elements or modals render, but actions do not persist or communicate with real external APIs.
* **Mock / Simulated:** Uses hardcoded calculations or client-side mocks instead of production third-party APIs (e.g., Razorpay simulator).
* **Not Found / Unavailable:** Completely absent from the accessible codebase (e.g., native Android Kotlin/Java source code).
